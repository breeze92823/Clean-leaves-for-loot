# Clean Leaves for Loot

Three.js (vanilla, no React) + Vite. A walled hub (studded plaza, terraced walls, shop stands, leaderboards, portal, training mounds) opening west onto a leaf field, plus a DOM HUD. Everything is procedural (canvas textures, SVG icons); the only imported model is the Bloxity base rig `public/avatars/player.glb`. Font: Fredoka (Google Fonts, falls back gracefully).

- `npm run dev` / `npm run build`. `VITE_DEV_MODE=true` (see `.env.example`) skips the Bloxity SDK/CDN.
- All tunables are in `src/config.js`. All Bloxity SDK calls go through `src/bloxity.js` and must never throw (SDK may be blocked).
- `src/player.js` is the player singleton + movement (`floorAt` is the single floor lookup, backed by `colliders.js`). `src/camera.js` chase cam (own yaw/pitch, one smoothed follow point, eased wheel zoom, speed pull-back/FOV, pulls in against `segmentClear` in colliders.js). `src/world.js` canvas-painted grass, sky shader, lights. `src/avatar/` = rig, cosmetics loader, `rig.js` (PoseBuffer + character-space bone binding) and `animator.js` (idle/run/airborne/landing + blower-arm hold; tunables in `ANIM`), ported from +1 Cut Grass Adventure.
- `src/hub.js` walls/floor/field/trees/clouds; `src/props.js` stands, NPCs, boards, portal, mounds, zone Luck signs (decorative, collidable). Solid things register boxes in `src/colliders.js` (yaw-rotated; tops within `HUB.stepUp` are walkable).
- `src/labels.js` in-world canvas text (repaints when the font loads); `src/textures.js` stud/drip/stripe/plank painters; `src/timers.js` shared countdowns.
- `src/hud.js` + `hud.css` + `icons.js`: HUD authored in 1920x991 px, each corner group scaled by `--s`. Values from `HUD_START` in config; tiles open a placeholder panel, buy buttons toast.
- Controls: WASD/arrows, Space jump, mouse look (pointer lock; right-drag where lock is refused), wheel zoom, Esc = portal menu + frees the cursor (click the world to resume), 1-3 hotbar.
- Loot loop: `src/piles.js` tiles the leaf field into piles per zone (hp = `LEAVES.piles.baseHp * luck^exponent`; clear time ~ hp / `blowerPower()` in `state.js`, no health bar). `leaves.js` tracks each pile's mound and fires `onPileCleared`; `src/loot.js` rolls drops by zone Luck (rules in `data/loot.js`), floats them, E collects into the Bag (`state.backpackMax`, 3 now; raise it to extend). `src/sell.js` = Sell Loot stand window (E), pays value x `cashMultiplier()`. `src/interact.js` = the "E" prompt. `src/state.js` = live cash/bag/power + `subscribe`. Back in the hub the field regrows (`LEAVES.piles.regrowDelay`) and loot left lying is lost. To make blowing stronger, raise `state.power` / multiply into `blowerPower()`.
